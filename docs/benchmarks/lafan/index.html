LAFAN1

40 motions · Unitree G1 · 29 joints

Original data

Use the 40 G1 CSV files under g1/, containing 264,705 source frames at 30 Hz. Rows contain root translation in metres, an XYZW quaternion and 29 joint positions in radians.

Download the original dataset ↗. Obtain and use the files under the upstream terms. Motion data stays in your local directory.

Evaluate a model

uv run --locked python evaluate.py --dataset lafan --data /data/lafan --output results/lafan

The command obtains the pinned checkpoint, converts it for full-batch inference, validates conversion, evaluates every selected motion and independently verifies recorded pose traces.

Evaluation

50 Hz control and scoring; four 5 ms physics steps per control period; sliding friction 1.0; Newton solver with 50 maximum iterations. Failure is the first pelvis height error above 0.25 m or gravity-Z error above 0.8. Rollout continues to the endpoint.
