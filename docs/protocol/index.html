03 · FAILURE & COMPLETION

A failure is recorded. The rollout continues.

Gravity-Z errorCompare the vertical components of gravity in the actual and reference pelvis frames: |g_actual,z − g_reference,z|, where g = Rᵀ(0, 0, −1). This value is dimensionless.

Sample boundariesIf the first failure is at 20 ms, completion is 0%; prefix metrics still include that failed sample. The initial t = 0 state is excluded from metric averages.

04 · TRACKING METRICS

Three alignments. Two time windows.

Mean per-body position error (MPBPE) averages Euclidean distances over the declared body origins and sampled frames within each motion, then weights motions equally. Root positions and joints use linear interpolation; orientations use SLERP.

05 · REPRODUCTION

Original author weights. Local evaluation.

Download the original motion dataset and an independent model repository. The command downloads the pinned author checkpoint, converts it locally, verifies inference, runs the full dataset and independently recomputes metrics on CPU.

git clone --recurse-submodules https://github.com/MotionChallenge-Project/MotionChallenge-heft
cd MotionChallenge-heft
uv sync --locked
uv run --locked python evaluate.py --dataset seed --data /data/seed/g1.tar.gz --output results/seed

Use Linux x86-64 with an NVIDIA GPU. --cache selects a shared local cache; --device selects the GPU. Results bind protocol, data, weights, source files, simulation settings and recorded traces. Numerical simulation failures do not receive a ranked full-suite score.
