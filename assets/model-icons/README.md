# Model and organization icons

Prefer institution and university logos, followed by verified model-family icons. Use unmodified assets with recorded origins; user-supplied institutional marks may be checked against official identity references. `sources.json` records source URLs and SHA256 hashes. Models without a verified icon use a centered uppercase initial.

Logos identify the respective projects and organizations; ownership remains with them.

`grit.svg` is a repository-rendered text identifier, not an official logo. Any2Track uses the existing Galbot mark; [GalaxyGeneralRobotics](https://github.com/GalaxyGeneralRobotics) identifies its organization as Galbot.
